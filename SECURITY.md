# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in MoonTUI, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

### Preferred: GitHub Private Vulnerability Reporting

Use [GitHub's private vulnerability reporting](https://github.com/Ermianr/moontui/security/advisories/new) to submit a report. This creates a private advisory where we can discuss and fix the issue before public disclosure.

### Alternative: Email

If you prefer email, send a report to the repository owner via the email address listed on their GitHub profile.

### What to Include

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (if you have them)

### Response Timeline

- **Acknowledgment**: within 72 hours of your report
- **Initial assessment**: within 1 week
- **Fix or mitigation**: depends on severity, but we aim for prompt resolution

We will coordinate with you on the timing of public disclosure. We request that you give us reasonable time to address the issue before making it public.

## Supported Versions

Security updates are applied to the latest release only.

## Scope

This policy covers the MoonTUI repository and the `@moontui/core` npm package.
